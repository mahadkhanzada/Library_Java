# Java Library Management System

A simple console-based Library Management System built with Java. The program allows users to browse different library shelves, select books, view basic information about the selected book, and exit the library.

## Features

- 5 different library shelves
- Books organized by class/semester
- Interactive console-based menu
- Book selection using user input
- Displays information about selected books
- Option to exit the library
- Input validation for shelf selection

## How to Run

1. Download or clone this repository.
2. Open the project in a Java-supported IDE.
3. Compile `Library.java`.
4. Run the program.
5. Select a shelf and then choose a book.
